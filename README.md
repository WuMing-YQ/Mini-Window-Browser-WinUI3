# 小窗浏览器 · WinUI 3 衍生版

一个面向 Windows 的便携小窗浏览器，用于置顶查看网页、视频与攻略。本版使用 C++/WinRT、WinUI 3 和 WebView2。

## 项目来源与关系

本项目基于 **[azurplain / Mini-Window-Browser](https://github.com/azurplain/Mini-Window-Browser)** 修改，是围绕个人使用需求制作的衍生版本。窗口控制、媒体操作、快捷键、配置等实现继续使用或改造了原项目代码；当前版主要重做了 WinUI 3 界面，并调整部分交互和窗口行为。界面重做不等于全部代码从零原创。

## 个人修改动机与范围

这些修改主要围绕我的个人使用需求，由我描述需求并借助 AI Agent 逐步完成：

1. **修改的起点**：我在《明日方舟》PC 端全屏运行时，遇到小窗整体隐藏没有触发的情况，因此产生了针对自己使用环境进行修改的想法。
2. **常驻显示的不透明度**：希望小窗整体常驻显示时，可以按个人观看需要调整不透明度。
3. **快捷滚轮调窗**：希望通过组合键配合鼠标滚轮，快速调整窗口大小。
4. **个人需求的贴边处理**：根据自己的窗口摆放习惯，调整贴边时的缩放锚点和屏幕边界处理。

在这一过程中，也借助 Agent 将整个应用界面重构为 WinUI 3。上述选择出于我的个人需求和使用偏好，具体操作见[当前版使用说明](docs/validation/winui-redesign.md)。

## 便携运行

1. 完整解压 `MiniWindow-WinUI3-x64-Portable.zip` 到可写目录。
2. 双击文件夹内的 `MiniWindow.exe`。保留旁边的 `app/` 和 `docs/` 文件夹，不能只复制 EXE。
3. 本版沿用原项目的管理员权限启动策略，会显示 UAC 提示。

构建目标为 Windows 10 2004 或更新版本、x64。需要已安装的 Microsoft Edge WebView2 Runtime；界面仅支持简体中文。便携包带有 WinUI 必需的 Windows App SDK 组件和原生 VC 运行库，不包含 AI／机器学习／Widgets 组件，也不包含 WebView2 浏览器内核。缺少 WebView2 时程序会报告错误，不自动下载安装。

程序配置保存在 `app/config.winui.ini`，网页资料保存在 `app/data/webview-profile`。升级前先退出旧版本、备份配置及网页资料；不要把自己的资料打进公开分发包。旧版配置迁移方式见[使用说明](docs/validation/winui-redesign.md)。

## 构建与验证范围

开发环境：Visual Studio 2026、C++ 桌面开发及 C++ WinUI 工具、MSVC v145、Windows SDK 10.0.26100.0。依赖版本固定在源码中的 `winui/packages.config`。

```powershell
# 仅编译，不启动应用或测试
./tools/windows/build_winui.ps1 -BuildOnly
```

便携打包使用 `tools/windows/package_winui.ps1`；该脚本需要源码同步阶段生成的 `source-manifest.json`，具体流程见[构建说明](docs/validation/winui-redesign.md#从源码构建)。
