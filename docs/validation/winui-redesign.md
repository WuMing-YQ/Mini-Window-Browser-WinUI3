# 小窗浏览器 WinUI 3 测试版

本版完整重做应用界面：主窗口、书签快捷列表、书签／预设／设置管理和独立沉浸控制面板。使用原生 C++/WinRT WinUI 3，网页由一个活动 WebView2 实例承载。

## 启动

完整解压文件夹，运行 `MiniWindow.exe` 并确认管理员权限提示。保留同目录 DLL、MiniWindow.pri 和资源子目录。需要 Windows 10 2004 或更新版本、x64，以及已安装的 WebView2 Runtime。本包自带 Windows App SDK 与原生 VC 运行库，不需要安装 Flutter、Dart 或 .NET 应用运行时。缺少 WebView2 时会显示错误，不自动下载。

此测试包目录与旧版本分开，不覆盖旧 EXE 或浏览器资料。默认新建独立网页数据。需要迁移时先退出旧程序，再把旧 `config.ini` 和相应网页数据目录复制到本包旁边；原文件保持不动。首次读取会备份旧配置并生成 `config.winui.ini`；损坏／不可写时显示错误，不报告保存成功。网页资料被旧程序占用时可选择独立测试资料。

## 主要操作

- 顶部书签按钮直接打开列表，点击条目在当前标签打开；列表底部“管理书签…”进入管理窗口。
- 齿轮按钮始终可见，直接进入设置。六类设置集中在左侧导航，右侧按分组卡片显示；书签／预设管理位于导航底部。未保存的编辑会提示保存、放弃或继续编辑。
- 预设按钮直接打开悬浮列表，选择条目后确认应用；列表底部“管理预设…”进入保存、重命名和删除页面。
- “设置 → 沉浸 → 打开沉浸控制面板”打开独立面板。打开／关闭面板不自动切换沉浸状态。
- 进入／退出沉浸保留窗口外框的位置和大小；隐藏的标题栏、工具栏空间交给网页，恢复后重新分配。反复切换不应累积缩小窗口。
- 两种模式分别保存基础不透明度 B。“移入减淡”的鼠标移入显示值为 `B × (1 − R/100)`，移出恢复 B。例如 B=80、R=50 时，移入显示40%。R=0不再减淡，R=100完全透明。
- 挖孔模式孔外显示 B，孔内完全透明；半径单位是物理像素，0–4000。鼠标位于面板上时不算移入网页。
- 变成完全透明后，可用面板“恢复普通模式”、沉浸快捷键或托盘恢复。普通模式恢复完整不透明、可点击状态。主动隐藏是独立操作。
- 普通且未最大化时，聚焦主窗口／网页后按住 Ctrl+Alt 滚动，每格放大或缩小5%。设置 → 快捷键可选择 Ctrl／Alt／Shift／Win 组合；窗口与行为可关闭。管理窗口、沉浸／隐藏／最大化期间不处理。
- 网页固定缩放仍支持25–500%；不包含固定1080P视口或自动适宽。渲染模式更改在下次启动生效。

## 从源码构建

VS2026：使用C++的桌面开发、C++ WinUI应用开发工具、MSVC v145、Windows SDK10.0.26100.0。执行 `tools/windows/build_winui.ps1` 默认构建并运行核心测试；`-BuildOnly` 仅编译。`tools/windows/package_winui.ps1 -SourceDirectory <stage> -OutputRoot <artifacts> -UserAcceptanceOnly` 生成待用户验收的正式权限包，不运行测试。包manifest记录依赖版本、源码摘要、文件SHA256与待验收状态。

源码同步工具 `tools/sync_windows.py` 只写入 `D:/Projects/Mini-Window-Browser` 下新的sources目录，排除配置、浏览器资料、构建输出和凭据；不执行其他项目脚本，不修改远程仓库。SSH使用已有密钥／agent，或通过环境变量SSHPASS传入密码。
