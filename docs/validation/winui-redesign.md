# 小窗浏览器 WinUI 3 便携版

本版完整重做应用界面：主窗口、书签快捷列表、书签／预设／设置管理和独立沉浸控制面板。使用原生 C++/WinRT WinUI 3，网页由一个活动 WebView2 实例承载。

## 来源与开发声明

本版是基于 [azurplain / Mini-Window-Browser](https://github.com/azurplain/Mini-Window-Browser) 的个人衍生版本，诚挚感谢原作者及贡献者。设置 → 诊断与关于提供原项目链接、衍生关系和简要致谢。

## 启动

完整解压文件夹，双击根目录 `MiniWindow.exe` 并确认管理员权限提示。根目录只放启动入口、README、`app/` 和 `docs/`；DLL、语言资源与程序本体集中在 `app/`，使用说明和许可证放在 `docs/`。请保留完整目录结构。需要 Windows 10 2004 或更新版本、x64，以及已安装的 WebView2 Runtime。本包自带 Windows App SDK 与原生 VC 运行库，不需要安装 Flutter、Dart 或 .NET 应用运行时。缺少 WebView2 时会显示错误，不自动下载。

便携包目录与旧版本分开，不覆盖旧 EXE 或浏览器资料。默认新建独立网页数据。配置与网页资料保存在 `app/` 内。升级前先退出旧程序，将旧版的 `config.winui.ini`（或旧 `config.ini`）及 `data/`、`XiaoChuang.exe.WebView2/` 等实际使用的网页资料目录复制到新版 `app/` 内；旧版若已有 `app/`，从该目录复制。原文件保持不动。首次读取会备份旧配置并生成 `config.winui.ini`；损坏／不可写时显示错误，不报告保存成功。网页资料被旧程序占用时可选择独立测试资料。

## 主要操作

- 顶部书签按钮直接打开列表，点击条目在当前标签打开；列表底部“管理书签…”进入管理窗口。收藏星标位于地址栏内，输入网址后按 Enter 前往。
- 工具栏始终显示后退、刷新、书签、预设、沉浸和设置；地址栏占据剩余宽度。窄窗将这些控件换行，不隐藏按钮。没有三个点更多菜单，窗口最大化／还原使用系统标题栏。
- 齿轮按钮始终可见，直接进入设置。六类设置集中在左侧导航，右侧按分组卡片显示；书签／预设管理位于导航底部。未保存的编辑会提示保存、放弃或继续编辑。
- 预设按钮直接打开悬浮列表，选择条目后确认应用；列表底部“管理预设…”进入保存、重命名和删除页面。
- 托盘菜单“沉浸控制”打开独立面板；沉浸参数也可直接在设置页调整。打开／关闭面板不自动切换沉浸状态。
- 进入／退出沉浸以网页内容区域宽高不变为准：进入时收起标题栏、工具栏并缩小外框，退出时恢复进入前的完整窗口。贴顶时网页上移到屏幕顶边，退出时下移腾出工具栏空间；贴底／贴角固定对应屏幕边缘，不贴边时尽量保留网页的屏幕位置。切换期间暂缓向 WebView 发送中间尺寸，避免反复切换累计缩小。沉浸快捷键／面板切换也会恢复进入前的最大化状态；“恢复普通模式”仍用于明确返回普通窗口。
- 两种模式分别保存基础不透明度 B。“移入减淡”的鼠标移入显示值为 `B × (1 − R/100)`，移出恢复 B。例如 B=80、R=50 时，移入显示40%。R=0不再减淡，R=100完全透明。
- 挖孔模式孔外显示 B，孔内完全透明；半径单位是物理像素，10–2000，通过滑动条调整。鼠标位于面板上时不算移入网页。
- 变成完全透明后，可用面板“恢复普通模式”、沉浸快捷键或托盘恢复。普通模式恢复完整不透明、可点击状态。主动隐藏是独立操作。
- 普通且未最大化时，聚焦主窗口／网页后按住 Ctrl+Alt 滚动，每格放大或缩小5%。设置 → 快捷键可选择 Ctrl／Alt／Shift／Win 组合；窗口与行为可关闭。管理窗口、沉浸／隐藏／最大化期间不处理。贴角时以该角为锚点；仅贴一边时固定该边，另一轴居中缩放；碰到新的屏幕边界（含任务栏区域）时立即按新贴边重新定位。
- 网页固定缩放仍支持25–500%；不包含固定1080P视口或自动适宽。渲染模式更改在下次启动生效。

## 网页输入

网页通过 WebView2 组合控制器显示，原生网页显示窗口直接把鼠标点击、双击、移动、拖动和滚轮传给该控制器；WinUI 区域保留备用转发。普通滚轮滚动网页；按住配置的组合键时优先调整窗口大小，只消费一次。沉浸状态继续穿透鼠标，退出后恢复网页输入。进入沉浸、隐藏、导航或弹出对话框时取消鼠标捕获，避免拖动状态残留。已移除排错期间的临时输入日志。

## 本次清理与审查

移除临时鼠标日志、只用于观察输入的事件订阅，以及设置页不再使用的沉浸弹窗回调。保留实际承担不同窗口输入路径、旧配置迁移、软件渲染的兼容逻辑。

修正拖动期间切换模式的鼠标捕获释放；视频自动调窗按实际网页视口计算比例，保留退出全屏的恢复尺寸，并忽略过期的异步比例结果。

## 从源码构建

VS2026：使用C++的桌面开发、C++ WinUI应用开发工具、MSVC v145、Windows SDK10.0.26100.0。执行 `tools/windows/build_winui.ps1` 默认构建并运行核心测试；`-BuildOnly` 仅编译。`tools/windows/package_winui.ps1 -SourceDirectory <stage> -OutputRoot <artifacts> -UserAcceptanceOnly` 生成待用户验收的正式权限包，不运行测试。包内 `docs/manifest.json` 记录依赖版本、源码摘要、文件SHA256与待验收状态。

源码同步工具 `tools/sync_windows.py` 只写入 `D:/Projects/Mini-Window-Browser` 下新的sources目录，排除配置、浏览器资料、构建输出和凭据；不执行其他项目脚本，不修改远程仓库。SSH使用已有密钥／agent，或通过环境变量SSHPASS传入密码。

## 输入与安全软件提示

已移除“输入时暂停快捷键”功能及其跨进程输入检测；WinUI 版本不再编译 InputGuard，也不使用该功能的系统焦点事件／UI Automation 查询。全局媒体快捷键可能在其他应用输入时生效，可在快捷键设置调整绑定。此变更不代表已证明360告警的唯一原因或保证不再出现提示。

沉浸参数采用带范围限制的滑动条；设置页没有重复的“打开沉浸控制面板”按钮。网页导航失败不再生成应用错误提示，网页自身的错误页仍由浏览器内核显示。
